# 蜃灵助手

蜃灵助手是一个面向 SillyTavern 长篇角色扮演的剧情辅助插件。它围绕“长线剧情不丢线、角色状态有沉淀、灵感入口随手可用”来工作：自动整理聊天记忆，维护大总结与剧情大纲，生成七日剧情机会，把关键回忆写入世界书，并提供日记、小剧场、词汇替换和上下文诊断等配套工具。

当前版本：`0.17.29`

仓库地址：

```text
https://github.com/dreamdana88/ShenLing-Extension
```

## 主要能力

- 长篇剧情归档：自动小总结、大总结、旧聊天分批归档与大总结合并。
- 剧情推进辅助：剧情大纲、章节推进条件、七日剧情机会与角色动向。
- 角色状态沉淀：情感档案、攻略好感度、回忆录世界书、角色日记与交换日记。
- 创作工具：小剧场生成、提示词收藏、文风收藏、词汇替换。
- 阅读体验：自动美化 `<memory>` 与 `<grand_memory>`，隐藏原始结构化文本。

## 模块介绍

### 自动总结

自动总结用于把聊天内容整理成可追溯的剧情档案。

- 自动小总结已改为消费 confirmed reply 队列；词汇替换仍保持即时处理。
- confirmed Summary 完成后直接提交 Emotion、Affection 与 Plot。
- 自动 Grand Memory 使用连续已总结楼层的安全归档边界。
- 已清理延迟 Summary 重构后的遗留 pending、fingerprint 与 metadata 双轨。
- 支持为 0 楼手动生成小总结。
- 支持重写或编辑指定楼层的小总结。
- 按间隔自动生成 `<grand_memory>` 大总结，并隐藏已归档区间。
- 支持重新生成上次大总结、合并多个大总结、扫描并分批归档旧聊天。
- 可配置正文读取规则，排除 `thinking` 等杂讯标签。
- 模块标题右侧可独立选择主 API 或副 API。

### 情感档案

情感档案用于记录角色关系、状态变化和隐秘动机。

- 从小总结或大总结中提取角色状态变化。
- 以待确认形式展示当前 swipe 的情感变化。
- 支持编辑、确认、删除角色情感档案。
- 生成前可注入最新情感档案，让后续回复保留关系连续性。

### 好感度

好感度模块用于记录可攻略角色对 `{{user}}` 的长期关系变化。

- 复用自动小总结判断细微好感变化，不额外增加每轮 API 请求。
- 当前 swipe 的变化先暂存，发送下一条消息时才写入整数十分位正式账本。
- 首次角色可使用通用五阶段，或自动调用一次所选 API 生成专属五阶段。
- 面板可查看当前值、阶段、最近变化，调整未提交变化与最新正式值。
- 已建档角色可直接编辑五阶段，或填写需求重新生成编辑副本；确认覆盖前旧阶段继续生效。
- 自动小总结或攻略追踪关闭时停止判断与正文注入，已有档案仍可查看和校准。

### 剧情大纲

剧情大纲用于维护当前故事的主线蓝图。

- 根据角色、世界书、近期剧情与用户期望方向生成章节大纲。
- 大纲包含故事核心、章节主题、剧情脉络、关键事件与推进条件。
- 支持保存草稿、编辑大纲、切换当前章节、勾选推进条件。
- 可在生成前注入当前章节状态，辅助模型保持主线节奏。

### 日程表

日程表用于生成未来七天的剧情机会供选择和参考。

- 根据当前剧情、大纲、世界书和期望方向生成七日剧情。
- 每日包含机会、可介入入口和角色动向。
- 默认折叠每日内容，点击对应日期展开。
- 支持“载入本日”“推进此机会”“引用动向”，把内容放入聊天输入框后自行调整发送。
- 可随时清空或重新生成。

### 回忆录

回忆录用于把已经完成的重要剧情节点写入当前聊天的回忆录世界书。

- 大总结完成后可自动提炼关键回忆候选。
- 也可以手动从最新大总结提炼。
- 新的大总结候选会追加到待确认区，不覆盖尚未处理的旧批次。
- 候选写入前可编辑标题、剧情时间、重要度、关键词、摘要和正文。
- 确认后写入世界书：蓝灯总览负责目录和唤起词，绿灯条目负责具体回忆。
- 已处理来源会记录，避免同一次大总结重复提炼。
- 模块标题右侧可独立选择主 API 或副 API，同时作用于剧情回忆提炼和设定采集生成。
- “设定采集”子页可从最近聊天、指定楼层或“大总结＋后续”生成世界书条目草稿。
- 可选材料仅包含当前角色卡、当前 Persona，以及当前角色卡绑定世界书中由用户明确勾选的条目。
- 草稿支持编辑标题、关键词、正文、插入位置和顺序；写入后按稳定 `captureId` 独立读回，只有核对成功的草稿会被移除，失败项可安全重试。

### 日记

日记模块用于为角色生成私人日记或交换日记。

- 按角色建立日记本，提供封面、目录和翻页式阅读界面。
- 用户内容为空时生成角色独白日记。
- 用户写下内容时生成角色给出的交换日记回复。
- 支持草稿收录、编辑、删除、导出。
- 支持封面和内页预设，也可上传自定义封面与纸张背景。
- 日记生成会参考近期剧情、总结、情感档案与世界书上下文。

### 小剧场

小剧场用于快速生成番外、侧幕、片段或美化页面。

- 支持提示词收藏、文件夹管理、搜索和排序；生成时的收藏夹选择器按文件夹折叠分组，默认只显示文件夹和条目数量。
- 支持文风收藏，并在生成时套用文风。
- 支持主 API / 副 API 生成。
- 生成时可读取近期聊天、小总结、大总结、情感档案与世界书上下文。
- 支持预览、编辑、保存回看、复制、重新生成、投到聊天输入框。
- 对 HTML/CSS 类结果会做基础安全处理，不执行脚本。

### 词汇替换

词汇替换用于对生成文本做统一修正或风格清理。

- 支持删除词、固定替换、通配替换三类规则。
- 支持规则启用/停用、编辑、删除、搜索查重。
- 支持批量导入和预览测试。
- 支持对当前楼层重新执行替换。
- 会作用于自动总结、剧情大纲、日程表、日记、小剧场等生成结果。

### 聊天美化

聊天美化用于把结构化总结渲染成更易读的卡片。

- 自动识别并美化 `<memory>` 小总结。
- 自动识别并美化 `<grand_memory>` 大总结。
- 原始结构化文本会隐藏，只展示整理后的卡片。
- 支持小总结和大总结主题切换。
- 小总结与大总结分开识别，避免互相误渲染。

### 设置与诊断

设置页用于管理模型、日志与上下文状态。

- “副 API 设置”用于配置 OpenAI-compatible 副 API。
- 支持多个副 API Profile、模型名配置与模型列表拉取；主/副 API 由各模块标题处选择。
- `提示词` Tab 集中编辑插件固定提示词；保存后作为本地覆盖用于下一次生成，恢复默认不会修改插件源码。
- 支持模块/提示词两级选择、协议校验、全宽长文本编辑、默认值对照，以及导出单一 UTF-8 修改稿。
- 提供通讯日志，记录各模块请求、响应、错误和耗时。
- 提供世界书上下文诊断，查看缓存、激活条目、过滤条目与 dry run 结果。
- 全局设置与聊天专属 metadata 分离保存。

## 安装

蜃灵助手依赖 TavernHelper（酒馆助手）。请先安装并启用 TavernHelper，再安装蜃灵助手。

在 SillyTavern 中打开：

```text
Extensions -> Install Extension
```

填入仓库地址：

```text
https://github.com/dreamdana88/ShenLing-Extension
```

安装后可在扩展设置中看到“蜃灵助手”。

## 更新

如果是通过 GitHub 安装的第三方插件，可以在 SillyTavern 的扩展管理中更新插件。

## API 说明

蜃灵助手支持两种生成方式：

- 主 API：复用 SillyTavern 当前连接。
- 副 API：使用插件设置页中配置的 OpenAI-compatible Profile。

副 API 支持：

- API 地址
- API Key
- 模型名
- 多 Profile 保存与切换
- 拉取模型列表
- `/v1` 兼容地址处理

不同模块可按各自设置选择主 API 或副 API。自动总结、回忆录提炼等会复用对应链路的生成配置。

### Generation 统一与超时语义（0.17.16）

以下能力已统一走 Generation Core，不再各自实现生成请求运输层：

- 自动总结
- 日程表
- 剧情大纲
- 小剧场
- 日记
- 好感度专属阶段表
- 回忆录设定采集

超时与错误语义：

- 主 API timeout 为 wait-only：上层停止等待后，底层生成可能仍在后台继续。
- 副 API timeout 可真实取消请求（覆盖响应头等待与正文读取阶段）。
- 用户主动触发的长文本生成统一等待上限为 300 秒（5 分钟）；主/副 API 超时提示文案不同。
- 失败通信日志可携带结构化诊断信息（错误码、阶段、安全 URL / 状态 / 响应片段等），且不记录 API Key 等敏感字段。

Phase 4 Generation 重构已在 `0.17.16` 收尾；延迟总结 / Swipe 定稿等生命周期工作属于后续 Phase，不在本版本声明范围内。

### 后台流式传输（0.17.24–0.17.26）

- 设置页提供统一「后台流式传输（推荐）」开关，默认开启，同时控制主 API 与副 API。
- 开启后优先后台真实流式接收，完整结束后一次性交给业务层显示；关闭后使用兼容非流模式。
- 0.17.24 接入：小剧场、日记、日程表、剧情大纲、好感度专属阶段建档、回忆录设定采集。
- 0.17.25 接入：手动 0 楼小总结、重写小总结、重新生成大总结、手动总档案压缩、旧聊天归档。
- 0.17.26 接入：confirmed 自动小总结、自动大总结、自动总档案压缩、自动回忆录提炼，以及 confirmed 首次好感专属建档。
- Emotion / Plot effects 不另调模型，继续在 Summary 完整写回后按 Emotion → Affection → Plot 串行提交。
- 运行时不支持或副 API endpoint 无法安全映射时，会在请求前兼容回退到 legacy，并只发一次请求。
- 流式请求一旦发出并失败，不会自动改发 legacy 重试。
- 大世界卡 / 多角色世界书的人设识别仍属后续好感模块完善范围，本版本未改变角色识别或世界书上下文策略。

### Manual Summary Chat Scope（0.17.27）

- Manual Summary 长任务（0 楼小总结、重写小总结、重新生成大总结、手动总档案压缩、旧聊天归档）加入轻量 Chat Scope Guard。
- 任务期间切换聊天时，迟到结果会丢弃，不会写入新聊天；不保存迟到模型正文，返回原聊天后可重新执行。
- 本版本未宣称 Auto Total / confirmed / Memoir / 世界书已完成同等保护，也未实现多步提交的部分回滚事务。

### Summary 结构拆分（0.17.28 / Phase 6A）

- Phase 6A 将 Summary 的 runtime、generation、state、manual guard、manual actions 与 archive 拆分为独立职责模块。
- 业务语义、Prompt、Transport、状态 schema 与 UI 行为保持不变。
- 本版本为纯结构重构；Phase 5A-1 用户实机已豁免未执行，Phase 6A 默认不要求实机。

### Affection 结构拆分（0.17.29 / Phase 6B）

- Phase 6B 将 Affection 的 runtime、Profile 阶段资料、Generation、build / pending 生命周期和 Prompt injection 拆分为独立职责模块。
- 好感数值、Prompt、Transport、状态 schema、提交语义与 UI 行为保持不变。
- 本版本为纯结构重构；默认不要求实机。

## 数据说明

- 全局设置保存在插件扩展设置中。
- 聊天专属数据保存在当前聊天 metadata 中。
- 回忆录写入前会核对当前聊天世界书：已确认过同一绑定则复用；未确认或绑定变化时询问使用当前书，取消则保留原书并新建、切换到蜃灵回忆录世界书；没有绑定时直接创建新书。
- 小总结和大总结写入聊天楼层正文，聊天美化只负责显示，不改变原始总结内容。
